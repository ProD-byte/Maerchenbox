# Märchenbox

Spieluhr-Filme für das Xiaozhi-Board `ostb-2st-wifi-double-mic`. Die Box zeichnet die Filme
live mit bis zu 30 Bildern pro Sekunde und erzeugt die Spieluhr-Musik selbst. Es gibt keine
gespeicherten Bilder oder Töne: Jedes Märchen ist Programmcode (`src/schneiderlein.cpp`).

## Bedienung

| Knopf | im Film / Startbild | im Märchenbuch |
|---|---|---|
| Start 1× | Start; im Film Pause / weiter (genau an derselben Stelle) | Märchen starten bzw. Einstellung ausführen |
| Start 2× | nächstes Märchen | – |
| Start lang | Märchenbuch | Buch schließen |
| Laut / Leise | Lautstärke (wird gemerkt) | umblättern (im Kreis: nach dem letzten kommt wieder das erste) |

Belegung am Gerät (so liegt es am besten in der Hand):

Die drei Knöpfe sitzen rechts am Gerät. Oben ist immer Lauter, in der Mitte Start, unten Leiser,
auch wenn das Bild um 180° gedreht ist (dann tauschen die Knöpfe oben und unten ihre Aufgabe).

| GPIO | Lage (Bild normal) | normal | Bild gedreht |
|---|---|---|---|
| 0 | oben | Lauter | Leiser |
| 39 | Mitte | Start | Start |
| 40 | unten | Leiser | Lauter |

Das Menü ist ein Märchenbuch: Beim Einschalten klappt es auf, jedes Märchen ist eine Doppelseite
(links das Cover des Märchens – Leinen in seiner Farbe, Goldtitel, bewegtes Bild im Bogenfenster, „Brüder Grimm“ –,
rechts „Es war einmal“, ein großes Erkennungszeichen – Apfel, Glasschuh, Turm mit Zopf … – und das goldene Siegel zum Starten), sonst nichts – Kinder können nichts verstellen. Solange eine Seite offen ist, spielt leise die
Melodie des Märchens, so erkennen auch Kinder, die noch nicht lesen, ihr Märchen.

**Einstellungen (für Eltern): Lauter und Leiser zusammen 3 Sekunden halten.** Dort: Höchste Lautstärke
(30 / 50 / 70 / 100 %, ab Werk 50 % = halb so laut; die 10 Stufen der Kinder liegen darunter), Helligkeit (25 / 50 / 75 / 100 %, ab Werk 50 %), Lesetempo
(normal / langsam / sehr langsam, ab Werk langsam: solange eine Sprechblase zu lesen ist, laufen Bild und Musik
in Zeitlupe, halb bzw. ein Drittel so schnell), Nutzungszeit (ab Werk 06:00–19:00: Start wählt
an/aus → von → bis, Lauter/Leiser verstellen in 15-Minuten-Schritten), Bild drehen
(180°, oben bleibt Lauter, wird gemerkt), WLAN einrichten, zurück zum Buch. Lauter/Leiser wählen,
Start führt aus; nach einer Minute ohne Taste geht es von selbst zurück ins Buch.

In den Einstellungen (Lauter + Leiser 3 s) „WLAN einrichten“ wählen (zurück: Start lang drücken), danach öffnet die Box das WLAN **„Märchenbox-Setup“**.
Mit dem Handy verbinden, WLAN wählen, speichern.

**Nutzungszeit:** Die Box holt die Uhrzeit über das WLAN (ohne WLAN gibt es keine Sperre). Außerhalb der
Zeit darf ein laufendes Märchen zu Ende gehen, dann kommt „Gute Nacht!“ mit Wiegenlied, Bildschirm und Ton gehen
aus. Wecken: Lauter + Leiser 3 Sekunden halten – dann bleibt sie eine Stunde wach. In der erlaubten Zeit weckt jede
Taste. Das WLAN bleibt im Schlaf an, damit Updates gehen.

**Akku:** oben rechts im Buch und auf dem Startbild (grün, ab 25 % gelb, ab 10 % rot mit „Bitte aufladen“,
goldener Blitz beim Laden), im Elternmenü mit Prozent und Volt. Gemessen an GPIO17 über Spannungsteiler 1:2,
Ladepin GPIO47 ist beim Laden LOW. Die Prozente kommen grob aus der Spannung (3,4 V = leer, 4,15 V = voll); beim
Laden liegt die Spannung etwas höher.

**Pause:** Start im Film hält Bild und Musik an (Bild wird dunkler, goldene Fortschrittsleiste); Start noch einmal
spielt an derselben Stelle weiter. Nach 10 Minuten Pause geht der Bildschirm aus, die Pause bleibt; ein Tastendruck
zeigt sie wieder. Start lang führt ins Buch.

## Updates über WLAN

```bash
pio run -t upload
```

Passwort: `ota_passwort` aus `../Himmelsstation/geheim.ini`. Per USB, falls die Box nicht mehr startet:

```bash
pio run -e ostb2st -t upload
```

## Aufbau

- `src/gfx.*` – Zeichnen: Polygone mit weichen Kanten, Kreise, Linien, Kurven, Text, Kamera
- `src/lcd.*` – NV3023-Display, Streifen per DMA
- `src/synth.*` – Spieluhr-Synthesizer (Noten, Glocken, Rauschen, Hall)
- `src/maerchen.h` – Schnittstelle eines Märchens: Bild zur Zeit t, Töne, Startbild, Vorschau fürs Buch
- `src/figuren.*` – gemeinsame Figuren, Kulissen und Effekte (Grundfigur mit `Aussehen`, Frauenfigur mit `FrauLook`)
- `src/melodien.h` – gemeinsame Spieluhr-Melodien
- `src/schneiderlein.cpp` – Das tapfere Schneiderlein
- `src/fuerchten.cpp` – Von einem, der auszog, das Fürchten zu lernen
- `src/aschenputtel.cpp` – Aschenputtel
- `src/rosenrot.cpp` – Schneeweißchen und Rosenrot
- `src/geisslein.cpp` – Der Wolf und die sieben jungen Geißlein
- `src/rapunzel.cpp` – Rapunzel
- `src/schneewittchen.cpp` – Schneewittchen
- `src/cinderella.cpp` – Cinderella (nach Perrault)
- `src/maxmoritz.cpp` – Max und Moritz (nach Wilhelm Busch)

## Speicher

Zwei Programmplätze zu je 7,9 MB (`partitionen.csv`), damit Updates über WLAN gehen; die Märchen sind Programmcode
und brauchen je etwa 30–50 KB, da passen weit über hundert. Die Einstellungen (`nvs`) liegen getrennt und bleiben bei
jedem Update erhalten. Eine neue Speicheraufteilung geht nur per USB: `pio run -e ostb2st -t upload`.

## Ältere Version

`aufnahme/`, `werkzeuge/mach_maerchen.py` und `werkzeuge/maerchen_hochladen.py` gehören zur
früheren Version, die die aufgenommene Märchenbox abgespielt hat. Sie werden nicht mehr gebraucht (der Bereich
